Background

Quality Control (QC) is an important part of the operational workflow, used to assess the quality of completed work within each Local Authority (LA) against defined quality standards. During the QC process, user performance is assessed based on factors such as the number of errors identified, overall quality percentage, and the different types of errors occurring. Currently, QC data is maintained in separate Excel sheets for each LA, with reporting also carried out separately. As a result, when management or team leaders request historical performance information, the relevant LA file must be located and searched manually, which can become increasingly time-consuming as more LAs and historical data are accumulated. This project aims to explore how the existing QC reporting process can be improved by centralising QC information and automating repetitive manual activities. A centralised dataset would provide a single source of truth for QC information while making it easier to analyse user performance, identify recurring error patterns, and track changes in performance over time. The project focuses on improving the QC reporting and analysis process rather than replacing the existing human QC process, and will explore data standardisation, automated performance calculations, user and error analysis, historical trend analysis, and an interactive dashboard that provides relevant visibility to management, team leaders, and individual users. This project is based on a real-world QC workflow and the operational challenges encountered within it; to protect confidentiality and privacy, all data used in the project is simulated and anonymised, with no real employee information, Local Authority identifiers, or confidential company data included.
