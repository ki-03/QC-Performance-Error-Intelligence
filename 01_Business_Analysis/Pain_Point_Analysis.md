## Pain Points in the Current Process

The current QC workflow involves several repetitive manual activities that can make reporting, analysis and information retrieval more time-consuming as the number of Local Authorities and historical QC records increases.

The main pain points identified within the current process are:

1. **New workbook required for every LA**  
   A separate Excel workbook must be created and configured whenever a new Local Authority is assigned, including setting up QC columns, metrics sheets and formulas.

2. **Historical performance requires searching old files**  
   Since QC information is stored separately for each LA, retrieving previous performance information requires locating and searching through historical workbooks.

3. **Inconsistent user-name formatting**  
   User names may be entered with differences such as additional spaces or inconsistent capitalisation. This can cause the same user to appear as different users when analysing the data and may require manual correction.

4. **Limited visibility of performance trends**  
   Although quality and error rates are calculated, identifying how a user's performance changes over multiple weeks, months or LAs is difficult when information is distributed across separate workbooks.

5. **User errors require manual review**  
   Errors identified during QC need to be manually reviewed to understand recurring error patterns for individual users and determine which areas may require additional attention.

6. **Management requests require manual consolidation**  
   Requests for historical, team-level or user-level performance information may require information to be manually located and consolidated from different LA workbooks.

### Overall Process Challenge
The current process is functional but relies heavily on manually maintained files, calculations and reporting activities. As the volume of LAs and historical QC information increases, these activities can make it more difficult to efficiently access information, identify performance patterns and provide consistent reporting.
These pain points provide the basis for analysing the requirements of an improved QC reporting and analysis process.
