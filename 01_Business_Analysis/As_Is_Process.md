## Current QC Process Workflow

The current QC process is carried out separately for each Local Authority (LA) using manually maintained Excel workbooks.

┌───────────────────────┐
│     New LA Assigned   │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│ Create New Excel      │
│ Workbook for LA       │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│ Set Up QC Columns     │
│ • Batch Name          │
│ • Date / Week         │
│ • User                │
│ • Error Type          │
│ • QC Result           │
│ • Comments            │
│ • Scenario            │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│ Create Metrics Sheet  │
│ & Add Excel Formulas  │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│      Begin QC         │
│   Sample Checking     │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│ Record QC Results     │
│ & Identified Errors   │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│ Calculate Performance │
│ • Quality %           │
│ • Error Rate          │
│ • Error Type Counts   │
│ • User Performance    │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│ Share Identified      │
│ Errors with Users     │
│ for Feedback          │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│ Create Error Example  │
│ Slides with Screenshots│
│ & Explanations        │
└───────────┬───────────┘
            ↓
┌───────────────────────┐
│      Complete LA      │
└───────────────────────┘
