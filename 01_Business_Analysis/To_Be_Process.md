## As-Is vs To-Be

| Area | As-Is | To-Be |
|---|---|---|
| Data storage | Separate workbook per LA | Centralised dataset |
| Data setup | Manual | Standardised |
| User names | May require manual correction | Automatically standardised |
| Calculations | Excel formulas | Automated processing |
| Historical analysis | Search previous files | Centralised historical data |
| Error analysis | Manual review | Automated analysis |
| Reporting | Manual consolidation | Dashboard |
| Error documentation | Manual screenshots/presentations | Standardised/automated where possible |
| Stakeholder visibility | Information requested manually | Stakeholder-specific dashboard views |
