# QC-Performance-Error-Intelligence
A BA and data analytics project that automates QC reporting, standardises data, identifies user error patterns, and tracks quality performance over time.

QC Performance & Error Intelligence System

📌 Project Overview
The QC Performance & Error Intelligence System is a Business Analysis and Data Analytics portfolio project designed to improve the way Quality Control (QC) performance data is collected, managed, analysed and reported.

The project is based on a real-world QC workflow encountered in a professional environment, where QC reporting relied heavily on manually maintained Excel files.

The current process creates challenges such as repetitive data setup, inconsistent data entry, fragmented reporting, limited historical visibility and difficulty identifying individual user error patterns.

This project explores how the process can be redesigned using Business Analysis, Python and Power BI to create a more centralised, standardised and insight-driven QC reporting solution.

Note: This portfolio project uses simulated/anonymised data. No confidential company data, employee information or proprietary identifiers are included.

🎯 Business Problem
The existing QC reporting process relies on multiple manually maintained Excel files.

When a new Local Authority (LA) or batch is introduced, QC analysts may need to create or modify reporting structures, copy formulas and maintain formatting manually.

The fragmented structure also makes it difficult to answer questions such as:

What is the quality performance of a particular user?
How has their performance changed over time?
What error types are they repeatedly making?
Which users or teams require targeted feedback?
How is overall QC performance changing?
Which error patterns are occurring across different LAs or batches?

There is also a data standardisation issue where the same user may occasionally appear under slightly different names because of inconsistent formatting, such as leading/trailing spaces or inconsistent capitalisation. This can cause the same individual to be treated as multiple users during analysis.

As a result, reporting can require significant manual effort and creates a risk of inaccurate or inconsistent performance analysis.

🎯 Project Objective
The objective of this project is to design and develop a centralised QC performance and error analysis solution that:

1. Reduces repetitive manual reporting work.
2. Standardises QC data before analysis.
3. Automates quality and error calculations.
4. Provides visibility into user, team and LA performance.
5. Identifies recurring error patterns.
6. Tracks quality performance over time.
7. Enables targeted user feedback.
8. Supports continuous quality improvement.
